CÔNG CỤ
TỰ PHÁT TRIỂN

Hai bộ công cụ Unity do Gà Mờ (GaMo Tools) xây dựng và dùng xuyên suốt Eclipse Strike.

True Input System

v1.0.7 · Input đa nền tảng

Một API duy nhất cho bàn phím – chuột, tay cầm và màn hình cảm ứng. Toàn bộ điều khiển, menu và cài đặt phím trong game chạy trên hệ thống này.

  • Joystick ảo & nút bấm trên màn hình
  • Nút kỹ năng định hướng kiểu MOBA
  • Điều hướng UI bằng tay cầm
  • Hỗ trợ ngắm (Aim Assist)
  • Đổi phím (Key Rebinding)
  • Con quay hồi chuyển (gyro) tay cầm

Blender-Style Workflow

Constraint & rigging cho Unity

Mang hệ thống constraint quen thuộc của Blender vào Unity: tay nhân vật bám súng, camera, ngắm bắn và vật lý phụ kiện đều được giải bằng bộ constraint này.

  • Transform · IK · Damped Track · Damped Track Chain
  • Constraint Scheduler: đồ thị phụ thuộc, sắp xếp thứ tự, phát hiện vòng lặp
  • Dynamic Bone chạy Job System cho tóc, dây, vải
  • Sự kiện animation theo thời gian (Motion Time Event)
  • Thao tác Editor theo phong cách Blender
